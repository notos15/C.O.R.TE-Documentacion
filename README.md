# Anexos y Documentación - Proyecto C.O.R.T.E.

Bienvenido al repositorio de anexos, documentación formal y diagramas de arquitectura del proyecto **C.O.R.T.E. (Control Operativo y Registro Total de Espacios)**, desarrollado por **Serruchos Dev Team** para la empresa **Cervecería Cuello Negro**.

---

## Descripción General del Proyecto

**C.O.R.T.E.** es una plataforma web interactiva basada en un **Gemelo Digital (2D)** diseñada para la gestión de espacio, inventario y logística dentro de la cámara de frío de Cervecería Cuello Negro (Valdivia).

El sistema optimiza la rotación de productos bajo la lógica **FEFO/FIFO** *(First Expired, First Out / First In, First Out)*, reduce los tiempos y movimientos de maniobra de los operarios e integra un algoritmo inteligente que sugiere de forma automática las posiciones ideales para lotes, pallets y barriles, respetando las normas legales de apilamiento (máximo 4 pallets por columna según el D.S. N° 594).
